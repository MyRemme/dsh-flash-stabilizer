# DSH Flash Stabilizer 0.1.10 - 补齐单字推理循环检测与异常告警

主要面向 DeepSeek-V4.1-Flash 在长上下文、高推理努力下的重复推理空转。本版修复检测覆盖和诊断问题，不是模型权重或服务端采样器补丁。

## 修复

- 补齐推理中持续“好。”等单字短句的漏检。仅放开推理短句分支，要求至少 90% 的短句单元重复、四字符片段新颖度不超过 15%，并连续多次确认。通用周期分支仍排除单字和数字数据。
- 保留变化编号的不确定性通知、代码围栏排除、正文不自动停止和用户待处理输入优先。此前有工具结果不会禁用后续推理防护。
- 监控异常显示“检测异常 · 仅传递输出”，关联对话、轮次与步骤并通知用户。只记录固定错误分类，不记录异常正文、自定义错误名或私人模型标识。
- 公开仓库更新检查和下载全部使用匿名请求，不读取环境 Token 或系统 Git 凭据。自动更新、空闲门槛、SHA-256、包身份及兼容校验继续保留。开发发布凭据只由独立发布脚本读取。
- 离线自检同时覆盖短句轮转和单字循环。

## 验证与边界

- 204 项自动化测试通过，包含旧新宿主适配器的异常降级、匿名更新及真实 DSH AgentLoop 的单字停止、单字正文对照、工具后循环防护。
- 交付包通过 35 个可用隔离宿主版本，2 个缺包不计通过，失败 0；保留取消语义验证。
- 实际桌面宿主原生热升级和 `guard` 离线自检通过；未停止进程或启动可见测试浏览器。
- 用户问题会话的 1,530 次助手记录：0.1.9 与本版均确认 330 次，未丢失原有检出；20 个既有历史循环全部回放检出。
- 同会话 23 次无正文、无工具循环在隔离宿主中全部收到停止确认，零后续请求。
- 评审提及的真实样本包含“好。”17,233 次，但夹杂其他短句；旧版与本版均在第 5,295 个推理字符检出。纯“好。”是另外验证出的检测盲点，不能混同为这条历史样本的漏检。
- 本轮没有新增提供方请求。历史回放和确定性宿主停止测试不等于官方模型在线恢复成功，也不能证明提供方停止计费。
