# DSH Flash Stabilizer 0.1.7 - 仓库入口与自动更新

面向 DeepSeek-V4.1-Flash、运行于 DeepSeek Harness 的推理重复监控与有限干预插件。本版新增仓库入口和自动更新模块；新安装或升级建议使用后续修复版 0.1.9。官方 API 匹配名为 `deepseek-flash`，兼容别名不作为服务端权重版本证明。

## 本版更新

- 插件面板加入可点击的 GitHub 仓库链接，以及当前版本、最新正式版、最近检查时间和更新状态。
- 提供自动更新开关、检查更新和安装更新按钮，沿用 DSH 的按钮、开关、主题及认证连接。
- 自动更新默认关闭。开启后在启动时及每 6 小时检查正式 Release；只有全部对话空闲、没有待处理输入或监控请求时才安装，下载结束后再次检查。
- 安装前校验 SHA-256、包名、版本、压缩包路径、安装脚本及 DSH/Node.js 兼容性，再交给 DSH 自身安装器处理。不会自动重启 DSH 或停止其他进程。

## 如何缓解推理空转

插件在本机检查流式推理的周期重复和间歇短句重复，经过连续确认后按模式处理：`observe` 仅记录告警；`guard` 请求停止本轮；`assist` 等本轮自行结束后提交有限软纠正；`auto` 自动停止后续接在当前发布矩阵中降级为观察。工具重复只告警，不自动重放工具。

这是运行期间的检测与缓解，不能修复模型权重，也不能保证不再发生采样退化。本版发布验证不等同于官方模型在线恢复效果实验。

## 公开仓库与隐私

仓库现已公开，源码与发布资产可直接查看、下载；公开 Release 支持未鉴权访问，不要求配置 Token。更新器仍先尝试读取指定环境变量或本机 Git 凭据助手，没有凭据时发送未鉴权请求。已有凭据只在宿主进程内使用，不保存或返回界面；更新检查不上传会话、推理文本、模型路由或诊断。SHA-256 是完整性校验，不是独立发布签名。

## 已知问题

标准安装将插件迁入 pnpm 目录后，本版可能无法识别真实宿主版本并降级为 `observe`。0.1.8 修复了安装锚点识别，0.1.9 进一步修复了在线升级时旧运行模块复用的问题。建议直接安装 0.1.9。

安装资产为下方的 `dsh-flash-stabilizer-0.1.7.tgz`；`checksums.sha256` 用于核对下载完整性。详细配置与限制见 [README](https://github.com/MyRemme/dsh-flash-stabilizer/blob/main/README.md)。
