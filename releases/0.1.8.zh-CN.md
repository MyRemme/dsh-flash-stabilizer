# DSH Flash Stabilizer 0.1.8 - 修复标准安装后的宿主识别

本插件面向 DeepSeek-V4.1-Flash 在 DSH 中的推理空转问题；官方 API 匹配名为 `deepseek-flash`。本版修复插件迁入 pnpm 目录后，无法解析宿主元数据而降级为观察模式的问题。新安装或升级建议使用后续修复版 0.1.9。

## 本版更新

- 使用 DSH 启动器提供的 `installAnchor` 读取实际宿主包版本，不依赖插件所在目录解析宿主。
- 仍要求宿主包版本一致；配置中的版本提示不能直接解锁未验证版本的干预模式。
- 保留仓库链接及自动更新模块，包括可选凭据、SHA-256 校验、版本兼容检查和空闲后安装；仓库现已公开。
- 网页自动化测试在加载页面前阻断音频与下载请求，以无窗口方式运行，避免提示音触发外部下载器；不修改日常浏览器或下载器设置。

## 验证结果

- 191 项测试通过，覆盖更新校验、六小时调度、失败后清除旧更新候选、标准安装的宿主识别及既有防空转回归。
- 35 个可用 DSH 发布宿主通过交付包回归，另有 2 个版本缺少宿主包，未计为通过。此结果不代表全部版本都支持自动更新服务。
- 真实隔离宿主分别验证了在线应用和需要重启两种安装结果，使用合成插件，没有发送模型请求。

## 已知问题与使用边界

正在运行的宿主可能复用旧入口或旧子模块，造成磁盘版本与实际运行行为不一致。0.1.9 使用带版本号的单一运行入口进一步修复此问题，建议直接升级到 0.1.9。

防空转仍属于运行期间的检测与缓解：确认推理重复后，`guard` 请求停止本轮；不能保证消除模型采样退化，也不能把宿主回归或离线回放当作官方模型在线恢复实测。

自动更新默认关闭，开启后在启动时及每 6 小时检查正式 Release。对话忙碌时等待，需要重启时明确提示；不会自动重启 DSH 或关闭其他进程。公开源码与 Release 无需申请读取权限，公开更新支持未鉴权请求；更新器仍优先尝试已有凭据。更新不上传会话、推理正文或私人模型标识。

安装资产为下方的 `dsh-flash-stabilizer-0.1.8.tgz`；`checksums.sha256` 用于核对下载完整性。详细配置与限制见 [README](https://github.com/MyRemme/dsh-flash-stabilizer/blob/main/README.md)。
