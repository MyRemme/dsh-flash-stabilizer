# DSH Flash Stabilizer 0.1.9 - 在线升级与静默测试修复

面向 **DeepSeek-V4.1-Flash** 的 DSH 推理防空转插件，官方 API 匹配名为 `deepseek-flash`。本版解决在线升级后仍复用旧运行模块、导致磁盘版本与实际防护行为不一致的问题，并完善标准安装时的宿主识别。建议从 0.1.7 或 0.1.8 升级到本版。仓库和 Release 现已公开。

## 本版更新

- 使用带版本号的运行入口，并将插件本地模块打包到同一入口，避免在线升级时加载旧入口或不同版本的子模块。
- 从 DSH 启动器提供的安装锚点读取真实宿主元数据，支持启动器仍在激活的阶段。保留版本一致性与兼容性检查，不通过手动填写版本解锁未知宿主。
- 插件面板提供可点击的 GitHub 仓库入口，以及当前版本、最新正式版、最近检查时间、更新状态、自动更新开关和检查/安装按钮。
- 网页测试全部后台无窗口运行，在页面加载前拦截提示音和下载资源，避免触发 IDM 等外部下载器；不修改日常浏览器或下载器设置。

## 如何缓解 LLM 采样退化

插件持续检查已接收的推理流，结合周期重复、间歇短句重复、覆盖率及新内容比例等证据，经过连续确认后才触发处理。对变化编号等难以确定的重复只通知用户。

- `observe`：记录检测证据和告警，不中断请求。
- `guard`：确认推理循环后，请求停止当前轮次，避免继续空转消耗；不自动重放工具。
- `assist`：当前回合自行结束后，等待空闲并提交有限的独立纠正回合，可能增加请求和费用，不能停止当前空转。
- `auto`：自动停止后续接只在宿主允许且验证通过时开放；当前发布矩阵未解锁此模式，会降级为观察。

插件界面可查看对应对话、轮次、步骤、重复证据、处理原因和实际动作。长时间没有输出本身不会直接被认定为低熵循环。“暂未发现循环”不保证后续不会发生，也不代表任务结果正确。

此方案是检测与缓解，不能修复模型权重或保证彻底消除采样退化。本次验证没有发送新的官方模型请求，不能将离线回放或模拟提供方测试解释成官方模型在线恢复实测。已有原生 Pi 20 次基线与 47 次条件补测未复现目标循环；实际问题会话回放检出 330 次，包括全部 23 次无正文、无工具候选。具体条件与限制见 [测试报告总览](https://github.com/MyRemme/dsh-flash-stabilizer/blob/main/TEST_REPORT.zh-CN.md)。

## 自动更新与隐私

自动更新默认关闭，开启后在启动时及每 6 小时检查此仓库的正式 Release。只接受递增正式版本；全部对话空闲、无待处理输入、无监控请求时才安装，下载后再次检查。安装前校验包名、版本、SHA-256、压缩包条目和宿主兼容性，再使用 DSH 安装器安装。

公开仓库与发布资产可直接访问，不要求配置 Token。0.1.9 仍先尝试指定环境变量或本机 Git 凭据助手，没有凭据时发送未鉴权请求，受 GitHub 匿名速率限制；失效的已有凭据也可能导致检查报错。凭据仅在宿主进程内使用，不保存或返回界面；更新不上传会话、推理正文、私人模型标识或诊断。SHA-256 用于完整性校验，不是独立发布签名。

需要重启时界面明确提示，插件不会自动重启 DSH、结束对话或关闭其他进程。未知或缺少更新服务的宿主会停用更新控件，监控仍独立工作。

## 验证结果

- 191 项测试通过。
- 35 个可用 DSH 发布宿主通过交付包回归；2 个版本缺少宿主包，未计为通过。此结果不代表所有宿主版本的自动升级路径均已实测。
- 实际 DSH 桌面进程确认 0.1.9 激活且处于 `guard` 模式，仓库链接、更新接口、实时监控和逐对话记录验证通过。
- 发布时的私有 Release 鉴权访问及安装资产摘要核对通过；仓库现已公开。未认证的 DSH 插件接口请求返回 401。
- 81 个源码文件与 429 个交付文件的隐私复查未发现实际私人路径、私人模型别名或原始会话。
- 网页验证没有打开可见浏览器窗口，没有新增模型请求，没有停止进程。

## 安装与已知限制

下载下方 `dsh-flash-stabilizer-0.1.9.tgz`，按 [README](https://github.com/MyRemme/dsh-flash-stabilizer/blob/main/README.md) 安装；已启用自动更新的安装会在下次检查且空闲时尝试升级。`checksums.sha256` 用于核对下载完整性。

从历史目录链接迁移到标准安装时，正在运行的宿主可能保留旧路径映射。遇到磁盘版本与实际运行状态不一致，应核对插件激活状态；本机迁移已备份并修复，不据此承诺所有宿主均可无重启升级。依赖审计中既有 DSH 测试宿主的依赖链仍有告警，本版没有替换宿主依赖。

仓库公开后的补审已核对 0.1.7、0.1.8、0.1.9 的远端安装资产，未发现实际私人路径、路由、会话 UUID 或凭据；GitHub 身份、测试统计和哈希仍公开保留。旧安装包内的私有仓库说明反映历史状态，以当前 [README](https://github.com/MyRemme/dsh-flash-stabilizer/blob/main/README.md) 和 [隐私审查](https://github.com/MyRemme/dsh-flash-stabilizer/blob/main/PRIVACY_REVIEW.zh-CN.md) 为准。本次只更新说明，没有替换安装包。
