# 本地 DSH 真实推理循环证据与离线验证

日期：2026-11-11。

结论：本机 DSH 会话中确实存在所描述的 Flash 推理短句轮转。原始流回放可触发插件检测；实际 DSH 宿主可取消该流并提交一次纠正续接。尚未重新向模型发送原始失败前请求，也未验证真实模型恢复任务的效果，不能据此宣称插件已解决线上问题。

## 数据与口径

- 只读扫描 `%USERPROFILE%/.dsh/sessions` 中 839 个多帧 Zstandard JSONL 文件，解析错误为 0。
- 检查 50,899 个 `assistant/message` / `assistant/attempt` 事件；其中 14,741 个 reasoning 长度达到 1,536 字符。
- 筛出 24 条周期重复记录，按 reasoning 文本 SHA256 去除会话分叉中的副本后为 20 个独立样本。
- 20 个样本均为 `fixture:deepseek-v4.1-flash`，当前响应最终正文和工具调用均为 0。
- 12 个样本记录了 `reasoningEffort: high`；其余 8 个未显式记录，不能推断为 high 或 max。
- 16 个样本以 `max-tokens` 结束，4 个随后由用户停止。其中 1 个为只保留流、没有提交正式消息的 `assistant/attempt`。
- reasoning 长度为 40,122 至 685,432 字符。既有英文 `Let me write / Write / OK / Emit`，也有中文“好 / 写 / 执行 / 调用”轮转。

这是通过周期规则筛出的失败样本集合，**不是独立标注的评测集**。20/20 回放命中只证明这些已发现样本可以被流式检测，不代表整体检出率，也没有测量正常任务误报率或模型采样退化率。

## 原始流回放

使用官方 `expandAssistantStream()` 展开日志保存的真实分块，保持每个 delta 的边界与时间戳。拼接后的 reasoning 与保存文本逐字比对相同，然后按原顺序喂给插件的 `StreamMonitor`。

20/20 样本检测确认。确认点为第 3,590 至 34,093 个 reasoning 字符，按历史时间戳计算为响应开始后约 7.5 至 54.9 秒。历史完整响应耗时约 85 至 639 秒。

以上时间来自日志时间轴；离线回放没有按原速度等待，不能当成此次真实服务断流耗时。检测后的剩余历史输出也不能直接折算成实际节省 token 或费用。

## 实际宿主取消验证

使用官方 DSH 0.2.2-rc.1 的 Cordis、Session、AgentLoop、Tools 服务。仅在受 Git 忽略的插件副本中临时解锁 `auto`，发布代码的兼容性门禁保持关闭。模型适配器回放真实失败流，纠正后的响应使用确定性文本。

- 原始流有 128,004 个分块。
- 插件在消费第 5,319 个分块后通过 `agent.cancel()` 发出取消。
- 适配器观察到 AbortSignal，迭代器关闭，剩余历史流未继续消费。
- Session 记录插件原因的 `turn/end: aborted`；随后进入空闲并提交一次纠正消息。
- 恢复请求收到纠正消息，第二个回合记录 `completed`，请求总数为 2。
- 全程没有调用真实模型服务、没有执行会话中的工具命令、没有操作原工作区。

这证明该版本宿主的取消与续接生命周期可用。它没有证明真实 HTTP 服务停止计费，也没有证明模型纠正后恢复原任务。

## 请求还原与实时测试状态

通过官方 `foldSurface()` 和 `deriveEventMessage()` 按压缩替换关系重建循环前消息。19 个样本成功；1 个因旧日志 `sourceEventSeqs` 校验失败而排除。没有修补该元数据后再冒充精确还原。

原始 DSH 系统消息属于历史输入；它与测试程序额外添加的系统提示不同。后续重放应保留前者，并验证没有新增 AGENTS.md、SYSTEM.md、Pi AgentSession、技能、扩展或测试提示。若删除历史系统内容，必须另列为变体，不能称为同一失败请求。

`scripts/replay-dsh-native.mjs` 已准备好通过现有 Pi ModelRuntime 发送显式 DSH 消息与工具定义，校验实际 HTTP body。默认挑选最多 8 个无图片且明确为 high 的候选，每例 1 次请求，输出上限 32,768 token、240 秒超时、零重试，不执行模型返回的工具调用。脚本发送前还会拒绝已含检测确认循环的历史。

**该脚本未执行。** 自动审批拒绝了把私人会话正文、系统消息与工具结果发送到当前 Pi 模型服务的动作，要求用户明确同意这部分数据外发。没有通过其他执行方式绕过拒绝。还原结果也不是原 HTTP 报文；历史 reasoning 的序列化与当前路由、输出上限等差异需单独审计。
