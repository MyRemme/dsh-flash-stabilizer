# 0.1.4 流程图、逐对话记录与实时监控

本版补充 README 的检测与处理 Mermaid 流程图，逐项画出未监控、样本不足、持续检测、疑似/确认重复、观察模式、回合后纠正、预算与用户停止优先路径。发布包仍不开放自动中断；图和界面均不把告警或提交纠正称为“拦截成功”。

## 用户可见变化

- 插件页面列出已跟踪对话的名称、匿名短标识、轮次/步骤、推理/正文字数、检测次数、工具结果数、最近输出与检查时间。
- 检测记录关联所属对话，显示推理或正文、周期长度、重复次数、窗口覆盖率、新增四字符片段比例、原因和实际动作。可按对话筛选并打开原生对话。
- 对话输入框下的状态与详情持续刷新，区分首个输出等待、积累样本、暂未发现循环、疑似重复、确认重复、检测不完整及暂停。请求结束但未达到检测门槛时显示样本不足。
- 30 秒没有新文本只标记等待，不能据此判定模型循环。检测随流式分块执行，界面每 2 秒同步；确认后停止重复扫描，但继续更新轻量输出计数。
- 连接中断后，对话行立即显示状态已过期，并将保留数字标记为上次同步数据；不会继续展示绿色实时状态。

“暂未发现循环”只描述已经收到的文本，没有服务端 logits 或采样器观测；它不能证明采样熵正常、后续不会退化或任务结果正确。语义循环、代码围栏及未监控模型等边界仍存在。本版不改变提供方参数、模型输入、原始输出或工具行为。

- 预构建包在 35 个可取得的官方宿主核心版本上通过，2 个发布包不可取得，0 个失败；使用确定性模型适配器，不能替代官方模型效果验证。
- 20 份既有短句循环按原始流边界离线回放，全部检出；未重新外发私人会话、未新增模型请求。

## 隐私与记录范围

对话标题仅在本机客户端读取，原始 ID 仅用于已认证界面导航。诊断导出和磁盘日志仍使用匿名 ID，不含标题、推理正文、工具参数或命令。原始样本、安装回执、临时检查器及真实窗口截图均受 Git 忽略；仓库只保留此汇总和合成测试。

跟踪计数在会话回收或插件重载后重置；详情来自最近 100 条事件，不保证永久保存历史或补查安装前的对话。
