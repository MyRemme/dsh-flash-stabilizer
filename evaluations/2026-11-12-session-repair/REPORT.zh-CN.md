# 实际会话驱动的 0.1.5 修复验证

## 数据与方法

用户提供的一份 DSH JSONL 会话，10,347 条事件、1,530 次助手记录。使用官方 `expandAssistantStream()` 恢复原始 delta，保留内容块边界与代码围栏。重建推理与保存推理全部一致，解码错误 0。只在本地回放，没有执行记录中的工具，没有发送模型请求，没有 Agent 提示注入。推理努力未记录，不能从日志证明 high 参数实际生效。

原文和模型路由不公开。下文轮次/步骤用于对照已给出的会话。额外模型标识只在本地配置中适配，不能把路由名当作官方模型版本证明。

## 修复原因

旧版要求至少 1536 字符与精确周期后缀，漏掉短句间歇出现、夹杂新文字的循环。新版增加推理短句频率和分布检测：512 字符开始、至少 128 新字符检查一次，最近 512 字符的多项数值条件连续三次成立才确认。规则没有硬编码会话里的词句。正文仍只使用原有精确周期规则。

新增 `guard` 在确认推理重复后请求宿主取消当前轮。它不自动续接、不执行或重放工具，不修改模型请求参数和历史。与既有 `assist` 回合后纠正分开，避免把等待结束当作已停止。

## 原始流回放结果

| 项目 | 0.1.4 | 0.1.5 |
|---|---:|---:|
| 确认重复的请求 | 0 | 330 |
| 独立短句筛选 349 次候选中确认 | 0 | 330 |
| 候选中既无正文又无工具的 23 次记录 | 0 | 23 |

独立筛选用于定位反复短句，不是人工逐条标注的真值。330 次确认均落在筛选候选中，其余 19 次没有全部满足连续确认条件；不能据此推算线上召回率或声称没有误报。普通变化推理、数字/时间列表、代码围栏、正文模板另有合成反例测试。

| 轮次 / 步骤 | 有效字符处确认 | 原流开始后确认 | 结果 |
|---|---:|---:|---|
| 67 / 2 | 未确认 | 未确认 | 有间歇证据，保留疑似状态 |
| 73 / 9 | 1028 | 2222 ms | 确认短句重复 |
| 79 / 4 | 1284 | 2557 ms | 确认；无正文、无工具 |
| 130 / 4 | 1026 | 2255 ms | 确认；代码围栏仍排除 |

延迟来自保存流的时间戳，不使用模型生成的时间文字。回放不代表实际节省的 token、官方 API 停止计费或下轮恢复质量。此前另一批 20 个历史精确循环样本仍全部检出。

## 宿主与回归验证

修复已完成内容块释放、重叠请求事件轮次绑定、撤销纠正状态和历史保留计数。单元与实际 Cordis / AgentLoop 测试覆盖：重复流取消、持久化停止确认、无追加请求、无纠正提示注入、无工具重放、用户停止优先和卸载。

兼容宿主测试通过的版本才开放防护停止，未知版本不调用取消。35 个可取得发布包的宿主使用确定性适配器验证；另 2 个版本缺少宿主包，不计运行通过。确定性宿主测试不能替代真实提供方的网络取消及计费验证。

额外将原会话 23 次无正文、无工具的输出流逐一送入隔离的 DSH 0.2.1-rc.2 宿主，使用本机配置的原始模型标识进行选择匹配。23 次均在消耗完原始流之前关闭上游迭代器，收到属于插件的持久化停止确认；每例只有一次回放请求、零后续请求。输入为合成占位任务，适配器只回放已记录的输出，不连接真实提供方。该验证覆盖真实宿主的检测到停止路径，不证明官方 API 的服务端取消行为。

发布验证：171 项自动化测试通过；35 个安装包宿主测试通过、2 个不可用、0 个失败；8 个桌面/手机及明暗主题视图通过布局检查。安装后验证运行模式为 `guard`、面板与对话详情可访问、未认证接口返回 401，没有新增模型请求。

```powershell
npm run check
node scripts/replay-session.mjs '<本地会话路径>' '.compat-cache/session-replay.json'

```

此修复缓解已经观察到的输出空转，并未改变服务端采样器或模型权重。下一轮仍可能再次退化；防护停止后需核实已执行结果再由用户继续任务。
