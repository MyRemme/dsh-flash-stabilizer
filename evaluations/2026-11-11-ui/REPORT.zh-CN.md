# 0.1.1 可见监控界面复审与验证

用户需要在 Harness 内看到插件是否工作，而非通过后台服务或日志代码查询。本版增加原生「Flash 防空转」侧栏入口、插件详情配置面板、状态角标和重复确认 / 纠正提交提示。

面板显示实际监控请求数、正在监控数、最近监控时间、确认重复总数及纠正提交总数。最近 100 条记录有界保存在内存，仅含去标识诊断字段；累计统计不受历史淘汰影响。默认不开磁盘日志，开关和写入错误在面板可见。

按钮包括刷新、暂停 / 继续、离线自检和导出诊断。暂停撤销待执行纠正，不取消模型或工具；恢复从下一请求开始，插件重载后恢复配置默认状态。自检不调用模型、不写入会话、不计入真实告警。纠正已提交不代表任务恢复成功。

## 复审

- 前端复用宿主 React 和已认证连接，不打包第二份 React，不开额外监听端口，不读取浏览器令牌文件。
- 桥接仅允许 owner principal，严格校验参数，拒绝多余字段和已取消请求。导出只返回内存去标识事件及统计，不接受文件路径。
- 真实宿主发现通用 RPC getter 的上下文归属差异；本版使用同一个认证路由的显式 owner 注册方法，保证路由 effect 归属本插件，并在缺少该方法时保留通用接口兼容路径。
- 暂停撤销恢复意图，旧轮询响应不能覆盖暂停结果。连接故障时显示未连接并禁用操作；请求超时、轮询、下载 URL 及订阅均有清理和上限。
- 保持 auto 门禁关闭。未新增真实模型恢复有效性的结论。

## 验证结果

- `npm run check`：121 项通过，9 个文件，类型检查及构建通过。包含 React / DOM 交互、旧轮询竞态、连接故障恢复，以及真实 Cordis 作用域中的注册 / 卸载测试。
- 最终安装包在 35 个已发布的官方宿主核心通过，2 个缺少 npm 宿主包的版本保持 unavailable。此结果仅覆盖核心监控，不代表全部旧版界面已验证。
- 使用当前安装的 DSH 0.2.1-rc.2 官方 HostConnectionService 离线验证路由注册和卸载，无模型请求。
- 用户 desktop profile 已安装 0.1.1，官方插件管理器确认 installed / enabled / active。客户端资源来自正式版本目录，发布内容与安装文件一致。
- 当前运行宿主中，通过官方登录 URL 到浏览器 cookie 的正常认证流程，真实 HTTP `snapshot`、`selfTest`、`export` 均成功；未认证请求返回 401。凭据只在内存使用，回执不含凭据。检查期间无模型请求，真实告警计数未增加。
- Harness 及两个 magpie 进程保持运行，未执行停止进程命令。临时诊断插件均移除。

桌面自动化工具在本机启动失败，因此没有声称亲自在当前窗口中点击或截屏验证。原生插槽注册由前端交互测试覆盖，当前宿主的客户端发布和认证通信已现场验证。用户刷新 Harness 页面后可从侧栏或插件详情进入面板。

本报告不包含用户原始会话、推理正文、工具参数或凭据。
