# 0.1.10 检测修复验证

## 范围

目标是补齐 DeepSeek-V4.1-Flash 推理短句检测盲点，避免监控异常被显示为正常，并简化公开仓库更新认证。未删除用户要求的自动更新，未按接口存在直接放开未知宿主停止权限。

## 修复前后

| 输入或条件 | 0.1.9 | 0.1.10 |
|---|---|---|
| 合成推理“好。”重复 17,233 次 | 未确认，最终状态 clear | 连续确认，状态 confirmed；1、7、73、4096 字符 delta 均在 1024 个检测字符以内确认 |
| 合成“哈。”、`a!`、补充平面字母短句 | 单字分支未覆盖 | 同样覆盖，仅适用于推理短句 |
| 单字正文、无分句单字数据、数字、变化编号、代码围栏 | 对照项 | 不确认、不自动停止 |
| 内部检测异常 | 仅全局无名计数，可能仍显示正常 | 会话检测标为不完整，固定错误分类及轮次可见并通知；原始输出继续传递 |
| 公开 GitHub 更新 | 尝试环境或 Git 凭据 | 检查、下载与跳转均匿名；发布脚本单独鉴权 |

单字短句采用至少 90% 单元覆盖、新颖度不超过 15% 和配置要求的连续确认；仍要求足够样本、重复分布覆盖窗口三个区段。不会仅因“好。”出现几次就停止。一般周期检测的两种不同字母要求没有放宽。

## 原始数据回放

- 用户提供的问题会话：10,347 条事件、1,530 次助手记录。两个版本均确认 330 次，新增确认 0、丢失确认 0。这是行为回归，不是误报率或线上召回率。
- 同会话中的 23 次无正文、无工具循环，使用最终交付运行时在隔离 DSH 0.2.1-rc.2 中全部确认停止，关闭原始回放流，没有追加请求或执行记录中的工具。
- 既有 20 个去重历史循环：保留原始 delta 边界，20/20 检出。
- 本地历史只读扫描：849 个会话文件、51,424 次助手记录。用“分句后某单字出现至少 80 次”筛出 18 次候选记录，两个版本均确认其中 5 次。候选未人工逐条标注，含副本，不能推出故障率。
- 评审所述“好。”17,233 次样本在候选中找到，331,502 个推理字符，无正文和工具调用；旧版与本版均在第 5,295 个检测字符以 phrase 方法确认。它不是纯单字周期，不能用纯重复合成实验认定该原始样本漏检。

离线比较命令：`node scripts/evaluate-single-letter.mjs <本地会话文件或目录> <0.1.9的dist目录> <本地报告路径>`。脚本不输出原文、路径、路由或会话 ID，完整会话扫描的确认统计仅针对候选子集。

## 自动化验证

`npm run check`：204 项测试通过，包括真实发布的 DSH AgentLoop 配合确定性适配器。单字循环和工具结果后的单字循环均确认停止，未追加请求；单字正文继续完成。旧新协议路径在检测失败时均保留原始输出并标记不完整。客户端状态、异常通知、匿名更新及既有校验继续通过。

交付安装包在隔离宿主矩阵中通过 35 个可用版本，2 个缺包仍不计通过，失败 0。新增的单字循环、单字正文和工具后循环场景均包含在各版本探针中。命令为 `node scripts/test-package.mjs artifacts/dsh-flash-stabilizer-0.1.10.tgz <本地结果路径>`；本轮结果留在忽略目录，没有用生成数据覆盖旧矩阵记录。

`benchmark-detection.mjs` 对 10,100 组输入的一般周期判定保持一致；既有短句长流的证据一致。256 Ki 字符单 delta 中位约 0.99 ms、73 字符 delta 约 3.97 ms，与 0.1.9 对照未见明显开销增加；本机微基准不代表所有硬件。

实际 DSH 桌面宿主通过原生管理器热升级到 0.1.10，模式为 `guard`，双场景离线自检通过，正式模块和客户端字节与构建产物一致，临时核验入口已移除。升级前确认全部代理和输入队列空闲；未停止 DSH 或 Magpie，也未启动可见测试浏览器。

本轮提供方请求 0，不向模型发送本地会话，不执行记录中的工具。尚未完成官方模型相同触发输入下的无插件/有插件在线恢复对照；本报告不宣称根治采样退化、测得费用节省或确认服务端停止计费。
