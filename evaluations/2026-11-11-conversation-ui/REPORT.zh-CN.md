# 0.1.3 原生界面与对话监控可见性

## 实现与复审

- 面板使用 DSH 原生 Button、Switch、图标和主题变量。统计、运行状态和事件采用无外层卡片的分区，复用宿主字体、边框、背景及明暗模式。
- 每个对话在原生 `conversation.composer.dock` 列表插槽中显示 Flash 状态，不替换聊天内容，不向模型历史或提示词写入状态信息。
- 详情使用已认证的 `session` 接口，只返回该会话的去标识事件、计数、覆盖状态及实际动作。校验 owner 权限、会话参数及取消信号；拒绝额外字段。
- 检测证据增加内容类型、轮次、步骤、周期与重复次数，不保存原始推理、正文、工具参数或命令。事件历史仍为全局最近 100 条，会话计数在状态回收或重载后重置。
- 当前请求与历史事件分别表示。新请求开始后清除当前事件摘要，但保留历史详情；模型不匹配、辅助请求、检测缺口、暂停和会话禁用不会显示为正常检查完成。
- `observe` 明确写明仅告警、未拦截、未中断。`assist` 的待纠正与已提交分别展示，均不表示恢复成功；中断请求也不等于宿主确认已停止。自动干预门禁保持关闭。

## 验证

- `npm run check`：144 项测试通过，9 个测试文件，类型检查和构建通过。新增会话隔离、鉴权、当前请求摘要、辅助请求、缺失信号、暂停中途检测缺口和会话界面交互验证。
- Playwright 使用本机隔离 Chrome，直接编译本地官方 DSH 原生控件及主题；1280×900 和 390×844 的明暗主题共 8 个视图通过。检查页面横向溢出、文字容器溢出、浮层边界、开关、自检和详情展示，并逐图检查。样本数据为合成夹具，不计入真实监控统计。
- 保持原始 delta 边界回放 20 份本地历史空转样本，全部检出，无新增模型请求。这不构成真实模型恢复成功的证据。
- 交付包通过 35 个可用官方核心宿主测试；2 个缺少 npm 发布包的旧版本仍 unavailable。该矩阵不代表全部旧版客户端界面通过。
- 已更新实际使用的 desktop profile 到 0.1.3。官方插件管理器返回 enabled / active，实际已发布前端字节与新包一致。正常认证 HTTP `snapshot`、`session`、`selfTest`、`export` 成功，未认证会话查询返回 401。
- 通过运行中的 DSH 正常 owner 登录，在隔离浏览器成功打开实际新版侧栏面板，未出现页面错误。该过程没有发送模型请求，也没有停止 DSH 或 magpie。
- 实际打开已有对话并点击输入框下方 Flash 状态，确认独立详情、待请求状态、会话计数与「无，未中断模型或工具」正确显示。空白的新会话占位页尚未渲染宿主的 composer dock；发送首条消息并进入对话后显示。验证没有发送消息。

宿主会将已解析的客户端文件路径缓存至进程结束。本次保留该路径，备份并更新本插件已发布文件，通过官方 `clientModules.rebuilt()` 通知前端更新；没有清除模块缓存或修改内部注册表。下一次正常启动会从 0.1.3 安装目录解析。

本报告不包含原始会话、凭据或本地安装辅助脚本。
